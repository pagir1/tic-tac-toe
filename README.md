# Nepaligamesus – Tic Tac Toe

A browser-based Tic Tac Toe game built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Features

- **2 Players** on the same device, or **vs Computer**
- Computer difficulty: **Easy** (random), **Medium** (mostly smart), **Hard** (unbeatable minimax)
- Players alternate who goes first each round
- Scoreboard for X, O and draws, saved in the browser between visits
- Winning line highlight, light and dark mode, keyboard and screen-reader friendly

## How to play

1. Open `index.html` in any modern browser (double-click it, or drag it into a browser window).
2. Pick a **Mode** (and **Difficulty** when playing the computer).
3. Click a square to place your mark. Get three in a row to win.
4. **New Round** clears the board; **Reset Scores** sets the scoreboard back to zero.

## Files

| File         | Purpose                                     |
|--------------|---------------------------------------------|
| `index.html` | Page layout: controls, scoreboard, board    |
| `style.css`  | Styling, light/dark theme, animations       |
| `script.js`  | Game rules, computer opponent, saved scores |
